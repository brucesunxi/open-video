# 优云智算全流程试运行

状态：新实例业务、ASR、TTS 已部署，实测结果与剩余事项以 docs/cloud-status.md 为准。下文保留分阶段验收计划。

## 1. 确认当前实例

提供控制台当前 SSH 主机与端口，以及本机是否已有 SSH 密钥登录。不能使用历史 PID、IP 或端口推断当前实例。

将 gpu-preflight.py 上传到服务器 /tmp 后运行：

```bash
python3 /tmp/gpu-preflight.py > /tmp/teacher-gpu-report.json
cat /tmp/teacher-gpu-report.json
```

脚本只读 GPU、环境版本、仓库提交、选定进程配置和服务路由；不读取密钥，不安装包，不停旧服务。若旧目录不存在，可据报告改为新实例部署。

## 2. 按依赖顺序接通

1. 独立 CPU 目录运行本系统，迁移真实资料前备份；DeepSeek 通过服务端密钥接入，先验收资料问答。
2. Qwen3-TTS Base 单独环境，以老师参考声音及人工核对转写建立声音档案。先比较 1.7B 与 0.6B 的音色和实际延迟，不将官方模型首包指标当作本系统延迟。
3. Qwen3-ASR 0.6B 独立服务，接通 /transcribe；Android WebM 和 iPhone MP4 录音都需实测。浏览器失败后自动兜底。
4. 读取当前 OpenTalking/OmniRT 源码协议并实现本系统真人适配器。保留已通过的 Python 3.10 / TensorRT 8.6 环境及当前 GPU 重新构建的引擎。不得直接向旧环境安装 Qwen 或升级 TensorRT。
5. 一位老师、一种形象先通过全流程，再扩充更多老师与卡通素材。
6. HTTPS 域名/平台地址、实际 TURN 映射、手机权限与网络测试完成后演示。

云端 Qwen 包装服务已实现并实测；真人播放器仍待接入。上传源代码包不等于全流程效果已验收。

## 3. 自然度路线

真人第一轮复用 FasterLivePortrait，实际比较同一照片与同一老师视频模板：口型、眨眼、眉眼、头部运动、肩部稳定。它不保证从任意照片生成自然手势。不能把放大嘴部运动作为表情自然的替代。

提供建议素材：一段清晰单人讲话视频（建议 1–3 分钟，无配乐，含正面与轻微自然转头），一张正面清晰照片；挑选约 10–20 秒干净音频并核对文字作为初始克隆样本。建议时长是采集目标，不是模型硬性要求。视频提取、音色建档尚需执行。

如果重点是卡通肢体互动，采用已绑定骨骼及表情的 VRM，制作倾听、思考、讲解、强调、鼓励、待机动作。单张卡通图片不会自动成为这个角色。卡通图片由照片驱动模型试验时不承诺所有画风有效。

## 4. 顺滑度验收（目标，不是已测成绩）

- 先以单会话 512 级人物画面为起点，记录实际 FPS、丢帧、音画偏移、显存峰值。
- 目标稳定约 25 FPS；音画偏移目标不超过 150 ms。连续 10 分钟无明显冻结，再扩展至 30 分钟。
- 20 轮中文问答记录停止说话到首个可听回复的 p50/p95；首轮目标 p50 <= 3 秒、p95 <= 5 秒，不满足就先减少生成量、做短句预取并评估模型规格。当前整段 TTS 协议可能达不到目标，需据测量升级流式输出。
- 点击打断后本地音频目标 300 ms 内停止，服务端迟到结果不能重新播放；当前并未实现全双工自动抢话。
- 空闲时自然眨眼和轻微姿态变化，回答时表情不过度；待机动画和语义动作应有平滑过渡，不能每句跳回同一姿态。
- 老师本人确认音色、停顿、专业词读音；不以未经测量的“相似度百分比”承诺。
- 用同一段知识讲稿比较 A/B 录屏：默认参数与自然动作参数，不仅比较演示视频。

音频为同步主时钟，帧队列有界，播放前按 turn_id 丢弃已取消内容；讲课可预生成短段音频，实时问答不能等待整篇长文完成。实际实现需在已有模型协议确认后落地。
