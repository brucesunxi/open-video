# 分数除以整数：换小单位继续分

课程来源：用户提供的 `assent/分数除以整数29.13.docx`。原件不随 Git 和部署包公开。保留足球场情境、4/5÷2 与 4/5÷3 的对比，以及“总量不变，换成更小的计数单位继续分”的教学主线。本文和 JSON 是改编教学设计，并非教师本人授课实录。

共 10 页：情境列式、分数意义、直接平均分、三份的困难、等值转化、继续计算、检验辨析、迁移练习、联系整数小数、整理挑战。

补充内容：
- 明确整个足球场是单位“1”，避免把部分误作整体。
- 区分等值改写 4/5=12/15 与除法结果 4/15；不能把两者混淆。
- 用“单位变小、个数变多、总量不变”解释转化。
- 增加乘法检验、大小估计、3/7÷2 练习和 2/3÷4 挑战。
- 不提前用乘倒数口诀替代本课对算理的探索。
