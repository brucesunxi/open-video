# 年长教师形象与随讲板书

新素材为原形象的衍生版本，目标年龄约 77–79 岁：增加灰发、面部及手部年龄细节，表情略严肃且慈祥，保留服装、身份特征和坐姿。使用内置 image_gen 编辑，素材保存在 output/teacher-materials/cartoon-teacher-elder-v3.png；该目录不提交 Git，服务器通过素材接口保存。原形象仍可选择。生成提示词保存在同目录 elder-v3-prompt.txt。

讲课画面新增老师与黑板的同框组合。桌面宽布局中板书约占 60%，教师约占 40%；窄容器与手机上下排列，避免公式过小。完整原课件仍位于下方，讲稿、音色、教学风格均不改变。

LessonBoard 按讲稿语义锚点显示和突出要点。GPU 配音根据当前媒体片段的 currentTime/duration 映射到讲稿位置，片段间累计偏移。属于段内近似的要点同步，不是逐字强制对齐；较长停顿可能造成少量提前或滞后。浏览器朗读使用 boundary 事件。暂停、缓冲时进度不自行前进，旧播放的回调不影响新播放。板书是网页清晰文字层，没有烧录到下载的 MP4 或 PPT 中。

验证：前端构建、既有后端测试、媒体时钟进度与取消回调测试，桌面与手机实屏布局检查。新图片改变缓存键，需要生成对应动画；已有其他形象的缓存保留。
