# 站姿数学老师

选定素材：`output/teacher-standing/standing-blackboard.png`。保留近八十岁的面貌、灰色卷发、深蓝服饰和首饰，正面站立，双手在腰前自然交叠。背景为简洁绿黑板，白色粗体文字分两行：“和马老师”“一起学数学”。不启用拿书和指板版本。

生成参考：`output/teacher-standing/standing-front.png`，来自现有 `output/teacher-materials/cartoon-teacher-elder-v3.png`。最终编辑要求是保留身份、年龄和姿态，移除书架、地球仪、植物和家具，仅保留木边绿黑板及指定标题。最终图已目视核对。

图片不是已渲染课程。现有引擎提供音频驱动口型、眨眼和轻微头动，身体维持参考姿态。新图片需要在 GPU 服务器生成独立的课程视频缓存。

部署更新后的源码、前端构建和该 PNG 后，在服务器项目目录使用应用虚拟环境运行（需要 Node；部署包包含与前端同源的断句模块）：

```sh
.venv/bin/python scripts/register-standing-teacher.py /tmp/standing-blackboard.png --activate
```

脚本上传唯一素材，使用前端相同断句规则依次准备该老师的已发布课程；全部完成后才切换默认形象。失败时保留原选择；可以重试并复用片段缓存。老师音色及教学资料保持原值，原坐姿图片保留，后台可切换。

本地验证：34 项后端测试（含独立形象课程缓存、切换及跨教师素材拒绝）、语音管线测试、18 页板书预览测试和生产构建通过。远程连接已恢复，正在执行 GPU 生成与上线验证；最终结果以本次验收记录为准。

实时对话共用所选站姿形象，原图黑板文字保持固定，不叠加课程板书。切换形象会重建对话播放器，取消旧形象的播放。讲课覆盖左侧 47% 的黑板区域，右侧人物完整保留。
