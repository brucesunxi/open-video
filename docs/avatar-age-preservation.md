# 动画年龄纹理保留

LivePortrait 的整脸重建和 MuseTalk 较大的下半脸融合区域会平滑原图年龄细节。新流程在动画模板构建阶段，通过反向光流将原始高分辨率人脸裁剪对齐到生成帧；在非眼睛和非嘴周区域保留原图皮肤纹理。嘴型融合椭圆收窄，H.264 CRF 从 25 调为 20，减少压缩对细纹的损失。

仍保留模型生成的眼部和嘴部，以免原图纹理把眨眼和发音覆盖。不能保证生成脸部逐像素与原图一致。每张模板只处理一次，不增加每段视频的光流计算。

缓存默认版本升级为 reference-skin-v1，旧媒体不再命中。部署时如果 MEDIA_CACHE_VERSION 已设置，需要同步升级。重新准备课程后，新视频独立保存。声音档案、原始照片和课程讲稿不改。
