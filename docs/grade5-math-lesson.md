# 五年级数学演示课：同样的单位，才能相加

知识点：异分母分数加法。课件共八页，包含旧知联系、分数单位、通分算理、计算、错解辨析、方法整理、迁移练习和分层巩固。

用户已确认所指老师为马芯兰。此课为原创演示设计，不是马芯兰本人教案、原话或授课实录。形象和声音沿用用户已选择的素材，不因本次课件更新改变。

设计参考公开报道中体现的教学理念：重视基本概念，建立知识之间的联系，引导学生由已有知识迁移到新问题，并照顾不同学习进度。具体落实为：从同分母加法出发，用共同分数单位解释通分，让学生解释结果而不只记步骤；用大小关系检查错解；提供基础练习与进阶挑战。
