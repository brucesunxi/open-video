# 讲课页聚焦布局

默认主界面仅显示课程选择、数字人与同步板书、页码、上一页／播放暂停／下一页。删除重复的提纲卡片、宣传说明及技术状态说明。

讲稿、动画缓存准备、恢复上次课堂、新会话和 PPT 下载放入“讲稿与课堂设置”；聊天放入“有问题？向老师提问”。两者默认收起，原功能保留。

手机端人物区缩短，板书保持 16px 正文，播放按钮至少 44px 高。控制条紧邻画面并使用底部 sticky 定位，考虑安全区；导航与课程切换继续可用。电脑版主教学画面扩展为单列，问答按需展开。

验证：375×667、390×844、1440×1000 浏览器视口中首次加载的播放按钮均在视口内，无横向溢出；折叠问答、课堂设置可以展开。播放管线回归测试通过。这里是浏览器尺寸模拟，未替代实际 iPhone／微信浏览器验证。
