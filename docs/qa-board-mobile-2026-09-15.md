# 手机嵌入板书修复

根因：普通课件预览的手机样式固定使用16px字号及大间距，覆盖嵌入式板书的比例布局。加载视频后尚未到达第一个板书锚点时，会显示过大的预览内容。

修复：为嵌入预览补全字号、分数、序号和留白规则，移除重复的预览底部提示。手机预览及正式板书统一为2.6cqw。自动滚动改用相对可视区坐标，切页、静音和预览复位；窗口尺寸变化时重新确认当前讲解行位置。

验证：真实Chrome内核、360/390/430/768/1440宽度，18页课程、820个板书状态，覆盖加载预览、各讲解锚点、结尾、静音阅读和页面复位。预览均无纵向裁切，当前讲解行均在可视区，页面无横向溢出及JS异常。语音分段/缓存整页播放/取消测试和生产构建通过。此为桌面浏览器尺寸模拟，不代表iPhone微信内核实机测试。
