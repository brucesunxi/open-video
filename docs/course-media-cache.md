# 课程音视频预生成

讲课页的“提前生成整课动画”按播放端完全相同的分段规则准备音视频，后台任务不依赖页面保持打开。显示实际完成段数、当前页和失败状态。重新准备会复用完整片段；服务重启后任务标为中断，可重试。

缓存位于 DATA_DIR/speech-cache。键包含老师、音色档案 ID、图片内容摘要、讲稿、模型服务地址及 MEDIA_CACHE_VERSION。原子写入并校验内容摘要；失败不写缓存。播放仍走登录保护的语音接口，命中缓存时不调用模型，返回 X-Media-Cache: hit。没有更改浏览器声音模式。

修改模型参数或在相同音色 ID 下更新音色后，应提高 MEDIA_CACHE_VERSION 并重启网页服务。缓存随服务器数据目录持久保存，占用磁盘；备份时可按需要排除 speech-cache。删除缓存不影响素材和课件，但需要重新生成。

基础缓存是完整的同步音视频片段；下方的按页播放层将它们合并为每页一个 MP4。临时插问、修改讲稿或更换素材需要生成对应内容。网络传输、浏览器解码及翻页切换仍有开销，不承诺零延迟。

## 按页视频直播放

已准备课程通过 `GET /api/courses/{id}/playback` 获取每页视频地址，前端提前加载当前页和下一页。点击后走原生 MP4／HTTP Range 播放，不经过语音合成接口和 base64 SSE；实时问答继续使用短片段流。

课前准备复用原有语音动画片段，通过 FFmpeg concat `-c copy -movflags +faststart` 合成每页一段；不重编码画面、不卡在片段下载边界。原合成音频中的自然停顿保留。板书使用记录的片段起点、时长和文字偏移，避免整页简单线性估算造成累积偏差。

部署需要设置 `FFMPEG_BIN` 为 FFmpeg 可执行文件路径（或提供 PATH 中的 ffmpeg）。旧版本 ready 任务只表示小片段已缓存；升级后重新点击课前准备，复用这些片段生成按页视频。输出位于数据目录 `course-playback/<signature>/`；签名包含讲稿、声音、图像内容和渲染版本。文件缺失或更换素材时不提供旧视频。已认证的视频 GET 支持字节范围和浏览器私有缓存，其余 API 保持 no-store。

验证涵盖视频无重编码合并、faststart 元数据顺序、缓存身份变化失效、HTTP 206 部分读取、不调用合成接口、原生预加载复用和板书时间偏移。

课堂会话在选择课程后提前准备。已准备视频先开始播放，再同步 start/resume 状态；同步失败会停止播放并提示错误。自动翻页等待状态同步完成，避免使用旧 revision；暂停先立即停止媒体，再保存状态。
